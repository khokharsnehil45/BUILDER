## 📖 Overview

**BUILDER** is an AI-powered venture architect and business strategy platform designed for founders, indie hackers, and product leaders.

It synthesizes structured venture blueprints:
1. **9-Box Business Model Canvas**: Customer segments, value propositions, unit economics, and key channels.
2. **10-Slide Investor Pitch Deck**: Problem, solution, market size (TAM/SAM/SOM), competitive moats, and financial ask.
3. **90-Day Go-To-Market (GTM) Execution Plan**: Step-by-step launch, alpha customer discovery, and distribution loops.

---

## ✨ Features

- 🧠 **AI Venture Strategy Engine**: Leverages local **Ollama** (`llama3.2:3b`) or **Google Gemini** to formulate business mechanics.
- 🏢 **Venture Dossier Database**: SQLite-backed startup profiles, stage tracking (`Idea`, `Validation`, `MVP`, `Scaling`), and saved modules.
- 💻 **Dual Interface**: Fast interactive Terminal CLI (`builder` / `BUILDER`) and sleek Web Workspace (`builder gui`).
- 🎨 **Cyberpunk Theme**: Symmetrical Cyberpunk Cyan & Electric Neon branding.

---

## 🚀 Quick Launch

### 1. Interactive Terminal CLI
```bash
builder
```
*(or `BUILDER`)*

### 2. Launch Web GUI Workspace
```bash
builder gui
```
Opens automatically in your browser at: **`http://localhost:8700`**
